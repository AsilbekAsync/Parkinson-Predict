# Parkinson's Disease Detection Model

This project aims to develop an AI model that can detect Parkinson's disease using data from patients.

## Requirements

- Python 3.8
- pandas
- scikit-learn
- joblib

## Data Source

The data used in this project is owned by Rabie El Kharoua and can be found on Kaggle at the following link: https://www.kaggle.com/datasets/rabieelkharoua/parkinsons-disease-dataset-analysis
